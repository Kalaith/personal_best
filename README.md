# Personal Best

A Godot 4.2.2 coaching game. You are a personal trainer running a gym out of a
backyard shed. Two clients walk in wanting to run the same marathon twelve
weeks from now: Jordan, a fit 20-year-old chasing a sub-3:30, and Peg, a
60-year-old newcomer who wants to finish inside the six-hour cut-off.

- Design: `gdd_personal_best.md`
- Decisions to review: `docs/DECISIONS.md`
- How to play from source: `.\Run.ps1`
- Agent and engineering rules: `AGENTS.md`

The toolkit is linked with `..\godot_toolkit\tools\Link-Toolkit.ps1 -ProjectDir .`
